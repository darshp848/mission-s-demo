# Publication contents

This public copy contains an explicit selection of project source, a metadata-sanitized
Simulink model, numeric results, generated body views and the telemetry video.

Excluded: recovery/session files, original reference photographs, local logs,
absolute user paths, raw MATLAB workspace dumps, compiled caches, environments,
downloaded dependencies, and saved Blender workspace files.

The model package differs from the validated local model only in author/date
metadata. Source provenance uses repository-relative model paths. Images have
text/EXIF chunks removed and the video has source metadata removed. The initial
commit uses the account's GitHub noreply address. No earlier local history is
included.

Pre-publication checks include secret scanning of the public file set and expanded
model archive, private-identifier checks, Python/JSON syntax checks, and a fresh
MATLAB run of the sanitized model. These checks reduce accidental exposure;
future contributors should review their own staged changes before publishing.
